**Severity:** High (production deploys blocked ~12 hrs)
**Resolved by:** Windows agent (Claude)

## Symptom

ทุก commit ที่ push ขึ้น GitHub ตั้งแต่ `642453d` เป็นต้นมา → Vercel GitHub integration build **ERROR**
แต่ `vercel deploy --prod` จาก local CLI → **READY** ทุกครั้ง

---

## Root Cause

`src/lib/identityService.js` ใน **git** ยังมี import path เก่า:

```js
// ❌ path เก่า — ไฟล์นี้ถูก migrate ออกไปนานแล้ว
import { generateCustomerId } from '../utils/idGenerator.js';
```

แต่ **local working tree** (uncommitted) ถูกแก้แล้ว:

```js
// ✅ path ถูกต้อง
import { generateCustomerId } from './idGenerators.js';
```

### ทำไม CLI deploy ผ่านแต่ GitHub ไม่ผ่าน

| Deploy method | Source | ผลลัพธ์ |
|---|---|---|
| `vercel deploy --prod` | Local files (`gitDirty: 1`) | ✅ READY |
| GitHub integration | Git clone จาก `github.com` | ❌ ERROR |

Vercel CLI deploy ใช้ local file system โดยตรง → ได้ version ที่แก้แล้ว
GitHub integration clone จาก git HEAD → ได้ version เก่าที่ import path ผิด

### Error ที่เห็นใน Vercel build log

```
./src/lib/identityService.js
Module not found: Can't resolve '../utils/idGenerator.js'

Import trace:
  ./src/lib/lineService.js
  ./src/instrumentation.js
  ./src/lib/identityService.js

> Build failed because of webpack errors
```

### ไฟล์ที่ถูกต้อง (ยืนยันว่ามีอยู่)

```
src/lib/idGenerators.js     ← ✅ มีอยู่ (ย้ายมาจาก src/utils/idGenerator.js ตั้งแต่ v1.6.0)
src/utils/idGenerator.js    ← ❌ ไม่มีแล้ว (deprecated)
```

---

## Fix Applied

**Commit:** `c22bf76`
**File:** `src/lib/identityService.js` line 10
**Change:** `../utils/idGenerator.js` → `./idGenerators.js`

---

## Lesson Learned

- Local uncommitted fixes ทำให้ CLI deploy ผ่านแต่ซ่อน bug ใน git → GitHub build fail
- ก่อน commit docs-only / infra changes ควร verify ว่า local working tree ไม่มี uncommitted source fixes ค้างอยู่
- **Protocol เพิ่มเติม:** หลัง merge conflict resolution → ตรวจ `git diff HEAD` ทุกครั้งก่อน push
