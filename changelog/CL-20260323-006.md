## Summary

เพิ่มระบบ task type 3 แบบใน Task Board — งานวันเดียว (SINGLE) มี time picker, งานต่อเนื่อง (RANGE) มี startDate→dueDate, และโปรเจค (PROJECT) มี deadline + milestone editor พร้อม calendar/weekly view แสดง spanning bars และ ◆ milestone markers ตามวันที่

---

## Changes

### `prisma/schema.prisma` — Task model fields
- `taskType String @default("SINGLE")` — SINGLE | RANGE | PROJECT
- `startDate DateTime?` — สำหรับ RANGE/PROJECT
- `timeStart String?` — HH:MM สำหรับ SINGLE
- `timeEnd String?` — HH:MM สำหรับ SINGLE
- `milestones Json?` — `[{id,title,date,type}]` สำหรับ PROJECT
- `completedAt DateTime?` — บันทึกเวลาเสร็จ
- `notionId String?` — link กับ Notion page

### `src/app/api/tasks/route.js` + `[id]/route.js`
- POST/PATCH รับ taskType/startDate/timeStart/timeEnd/milestones
- Validation: taskType ต้องเป็น SINGLE|RANGE|PROJECT

### `src/components/TaskPanel.js` (909 → 1225 lines)
- **Constants**: `TASK_TYPE_CONFIG` (icons/colors/labels), `MILESTONE_TYPES` (brief/review/meeting/submit/other), `taskSpansDay()` helper
- **TaskModal**: 3-card type selector → conditional fields (time picker สำหรับ SINGLE, date range สำหรับ RANGE, deadline + milestone editor สำหรับ PROJECT)
- **Milestone editor**: add/remove rows, เลือก type, กรอก title + date
- **TaskCard**: แสดง time badge (HH:MM–HH:MM) / range arrow / PROJECT deadline + checkpoint count ตาม type
- **WeeklyView**: RANGE/PROJECT tasks แสดงเป็น colored spanning bars ข้ามวัน (สีม่วง=RANGE, สีทอง=PROJECT)
- **CalendarView**: spanning bars ใน grid cells + ◆ diamond marker บน milestone dates + selected-day panel แสดง milestone details

### `CODEBASE_MAP.yaml` (new file)
- 11 domains: marketing/inbox/customer/kitchen/procurement/inventory/hr/sales/analytics/infra/tasks
- แต่ละ domain: repo file, key_functions, api_routes, components, env_vars
- session_start_files, source_of_truth, auth/RBAC roles, id_formats
- architecture rules + conflict_resolution matrix

## Known Gotchas
- `taskSpansDay()` เปรียบเทียบ ISO date string — timezone offset อาจทำให้ first/last day off-by-1
- WeeklyView spanning bars ใช้ CSS `-ml-2` bleed — เห็น gap เล็กน้อยระหว่าง cells (CSS grid limitation)
