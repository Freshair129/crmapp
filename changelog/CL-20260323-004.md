## Changes

### `src/components/EmployeeManagement.js`

#### New Hooks + Utility Components

- **`useCountUp(target, duration)`** — custom hook ใช้ `requestAnimationFrame` + ease-out cubic; reset เมื่อ `target` เปลี่ยน
- **`AnimatedMetricValue({ value })`** — parse string format (`฿12k`, `72%`, `5`) → animate numeric part → re-format; fallback ถ้า parse ไม่ได้
- **`AnimatedBar({ norm, color, delay })`** — `motion.div` width 0 → `${norm}%` พร้อม glow shadow + staggered delay

#### ScoreRing — Arc Draw-in

- `motion.circle` `initial={{ pathLength: 0 }}` → `animate={{ pathLength: score / 100 }}`
- duration 0.9s, ease `easeOut`, `drop-shadow` filter ตามสีของ ring

#### Sparkline — Line Run + Area Fade

- `motion.path` line: `pathLength` 0 → 1, duration 1.1s
- `motion.path` area fill: opacity 0 → 1, delay 0.8s
- `motion.circle` end-dot: scale 0 → 1, delay 1.1s

#### Progress Bars (Top Metrics)

- เปลี่ยนจาก `<div style={{ width }}>`  → `<AnimatedBar>` พร้อม stagger delay ทีละ 0.1s ต่อ bar

#### Score Number Count-up

- `const animScore = useCountUp(score)` — แสดง `animScore` แทน `score` ตรงๆ

#### Animation Retrigger Bug Fix (สำคัญ)

**Root cause:** `employees.map()` render ทุกการ์ดพร้อมกัน — component ไม่ unmount เมื่อสลับการ์ด → hooks run to completion ครั้งเดียว ไม่ reset

**Solution:** แยก `MiniDashboard` (wrapper) + `MiniDashboardContent` (content):

```js
function MiniDashboard({ emp, linked, barColor, isActive }) {
    const [animKey, setAnimKey] = useState(0);
    useEffect(() => {
        if (isActive) setAnimKey(k => k + 1);
    }, [isActive]);
    return <MiniDashboardContent key={animKey} emp={emp} linked={linked} barColor={barColor} />;
}
```

- `isActive` = `offset === 0` (การ์ดด้านหน้า)
- ทุกครั้งที่การ์ดถูกแอคทีฟ → `animKey++` → `MiniDashboardContent` remount → animations เล่นใหม่ทั้งหมด

#### Overview StatCard Enhancements

- **`StatCard`** รับ `rawValue` (number) + `format` (fn) ใหม่ — ใช้ `useCountUp` internally เพื่อ count-up display
- backward compat: ถ้าไม่มี `rawValue` → แสดง `value` (string) เหมือนเดิม

#### Overview StatCards สำหรับ SALES / ADMIN

แทนที่ Orders card ด้วย `%ปิดการขาย`:

| Card | Data | Animation |
|---|---|---|
| ลูกค้าที่ดูแล | `assignedCustomers.length` | count-up |
| ยอดสะสม | `totalRevenue` (฿ format) | count-up |
| %ปิดการขาย | `Math.round(validSales / assigned × 100)` | count-up + sub "N/M ออเดอร์" |
| Role | `getRoleMeta(emp.role).label` | static (string) |

```js
const validSalesCount = sales.filter(s => s.status !== 'CANCELLED').length;
const closeRate = assignedCustomers.length > 0
    ? Math.round((validSalesCount / assignedCustomers.length) * 100)
    : 0;
```

## Known Gotchas

> ⚠️ `animKey` increment: ถ้า `isActive` เปลี่ยนเร็วมาก (rapid swipe) อาจ remount หลายครั้งในเวลาสั้น — ไม่มีผลกระทบทาง UX เพราะ animation ใหม่ก็จะเริ่มต้นใหม่เสมอ
> ⚠️ `AnimatedMetricValue` กับค่า `0`: ถ้า target = 0 → count-up จะข้ามทันที (useCountUp return 0 โดยไม่ animate) — พฤติกรรมถูกต้อง
> ⚠️ `closeRate` divide-by-zero: guard `assignedCustomers.length > 0` อยู่แล้ว — return 0 ถ้าไม่มีลูกค้า
