## Summary

เพิ่ม `yieldPercent` (% ที่ใช้ได้หลัง prep) บน Ingredient — ตั้งแต่ schema/DB ไปถึง UI ครบทุก layer โดย `calculateStockNeeded` ตอนนี้คำนวณ gross purchase qty โดยอัตโนมัติ เช่น ปลา yieldPercent=80 → ต้องซื้อมากกว่า 25% เพื่อได้ usable qty ตามที่ต้องการ

## Changes

### Schema + DB
- `prisma/schema.prisma`: เพิ่ม `yieldPercent Float @default(100) @map("yield_percent")` บน `Ingredient` model
- Supabase migration: `ALTER TABLE ingredients ADD COLUMN IF NOT EXISTS yield_percent FLOAT NOT NULL DEFAULT 100`

### Repository — `kitchenRepo.js`
- `upsertIngredient`: รับ `yieldPercent` param — update แบบ conditional spread (ไม่บังคับ), create ใช้ `?? 100`
- `calculateStockNeeded`: สูตรใหม่ `qtyNeeded = qtyPerPerson × students × (100 / yieldPercent)` แทนที่ 1:1 เดิม — round 3 decimal places, expose `yieldPercent` ใน return object ด้วย

### API — `src/app/api/kitchen/ingredients/[id]/route.js`
- PATCH: validate `yieldPercent` 1–100, error 400 ถ้าออกนอกช่วง
- ถ้ามีแค่ `currentStock` → ใช้ fast path `updateStock()` เดิม
- ถ้ามี `yieldPercent` หรือ field อื่น → ส่งต่อ `upsertIngredient()` ทั้งชุด

### UI — `KitchenStockPanel.js`
- คอลัมน์ `YIELD %` ใหม่ในตารางวัตถุดิบ — แสดง badge สี:
  - 🟢 `≥90%` — emerald (เสียน้อย ปกติ)
  - 🟡 `70–89%` — amber (เสียพอสมควร)
  - 🔴 `<70%` — red (เสียเยอะ ต้องระวัง)
- คลิก badge → inline edit input (Enter ยืนยัน / X ยกเลิก)
- ฟอร์มเพิ่มวัตถุดิบ: เพิ่มช่อง Yield % (default 100, placeholder hint)
- State ใหม่: `editingYieldId`, `editYieldValue`

## Verification

```bash
# ตรวจ DB
SELECT ingredient_id, name, yield_percent FROM ingredients LIMIT 5;

# ตรวจ PATCH
curl -X PATCH /api/kitchen/ingredients/ING-001 \
  -d '{"yieldPercent": 80}' -H 'Content-Type: application/json'
# → 200 { ..., yieldPercent: 80 }

# ตรวจ validation
curl -X PATCH /api/kitchen/ingredients/ING-001 \
  -d '{"yieldPercent": 150}' -H 'Content-Type: application/json'
# → 400 { error: "yieldPercent must be between 1 and 100" }

# ตรวจ calculateStockNeeded (ปลา yieldPercent=80, 1kg/person, 5 students)
# → qtyNeeded = 1 × 5 × (100/80) = 6.25 kg (ไม่ใช่ 5 kg เหมือนเดิม)
```

## Known Gotcha

> ⚠️ `calculateStockNeeded` ต้องการ `ingredient.yieldPercent` ใน BOM include — ถ้า Prisma include เปลี่ยนแปลงในอนาคต ต้องตรวจว่า field ยังถูก fetch มาด้วย
> ⚠️ existing ingredients ทุกตัวมี `yieldPercent = 100` (no waste) — ต้องให้ Head Chef ระบุค่าจริงทีละตัวผ่าน UI ใหม่
