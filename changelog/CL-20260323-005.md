## Summary

Full RBAC redesign — ระบบ role ใหม่ 12 ตัวแทนที่ระบบเก่า 9 ตัว โดยใช้ prefix S (Special) และ R (Regular) พร้อม permission levels F/A/R/N ต่อ domain เพื่อให้ละเอียดและยืดหยุ่นกว่าเดิม รวมถึงเพิ่ม Employee Grade system (S/A/B/C/D) สำหรับ performance rating

## Changes

### `src/lib/permissionMatrix.js` — Complete rewrite
- **New ROLES[]**: `['DEV','TEC','MGR','MKT','HR','PUR','PD','ADM','ACC','SLS','AGT','STF']`
- **Permission levels**: `F` = Full CRUD, `A` = Approve, `R` = Read Only, `N` = No Access
- **7 domains × 6 actions × 12 roles** — matrix ครบทุก combination
- **`can()` helper**: ตรวจ multi-role แบบ additive union
- **`hasHigherPrivilege()`**: ใช้ ROLE_HIERARCHY numeric level

### `src/lib/rbac.js` — New hierarchy
```
ROLE_HIERARCHY = {
```

## Known Gotchas

- **NEXTAUTH_SECRET rotation**: ต้อง rotate ใน Vercel เพื่อ invalidate session เก่าที่ยังมี role code เก่า
- **Multi-role UI**: ยังไม่มี UI assign multi-role — ต้องใช้ SQL ตรงๆ
- **Grade = null**: existing employees ทั้งหมดมี grade = null — ต้องให้ผู้จัดการ assign ทีละคน
