# CL-20260323-008 — Package POS Integration + QR Attendance + POS UX Improvements

**Date:** 2026-03-23 | **Version:** v2.2.0 | **Severity:** MAJOR
**Tags:** #pos #package #enrollment #attendance #qr #vat #registration #ui

## Changes

### Package POS Integration
- **Schema**: `PackageEnrollment.qrToken` (unique), `PackageEnrollmentCourse.enrollmentItemId` (link to hours tracking), `Enrollment.packageEnrollmentId` (back-ref to package)
- **`packageRepo.js`**: `getActivePackagesForPOS()` — POS-optimized query; `createPackageEnrollment()` rewritten — single `$transaction` creates PackageEnrollment + Enrollment + EnrollmentItems + PackageEnrollmentCourse with QR token; `getPackageEnrollmentByQrToken()` for scanner
- **`GET /api/packages/pos`**: lightweight endpoint for POS to load active packages with courses/gifts
- **`POST /api/attendance/scan`**: QR scan → lookup enrollment → create ClassAttendance → update hours → check cert threshold
- **PremiumPOS.js**: loads packages alongside products; Package cards in "แพ็คเกจ" category with discount %, gifts badge, swap badge; PackageSelectionModal for swap group course selection; cart shows full breakdown (courses + prices + gifts value + discount + final price); processOrder creates PackageEnrollment for package items

### Customer Package Inventory
- **`CustomerPackageInventory.js`** (new): shows customer's purchased packages with course progress bars, hours completed/total, cert level, QR token display, gift list

### Attendance Scanner
- **`AttendanceScanner.js`** (new): QR token input → enrollment preview → course selection (if multiple) → hours + schedule + note → POST scan → success card with cumulative hours
- Sidebar: "สแกนเช็คชื่อ" (QrCode icon) added to OPERATIONS group for MGR/MKT/PD/ADM/SLS roles

### Order Type — Course vs Food
- Order Type modal now dynamic based on cart contents:
  - Courses/packages → 🏫 On Site / 💻 Online
  - Food items → 🍽️ Walk In / 📦 Take Away / 🛵 Delivery
  - Mixed cart → all 5 options
- Default type auto-set based on cart

### Customer Registration UX
- ⚡ สมัครเร็ว (phone only, one tap) + 👤 สมัครปกติ (full name form) always visible — no need to search first
- Back button returns to registration options instead of closing modal

### VAT Toggle
- Inc. (default): prices already include VAT, tax shown as "(รวมแล้ว)"
- Exc.: VAT 7% added on top
- Toggle pill buttons in cart totals section

## Known Gotchas
- `qrToken` is nullable — existing PackageEnrollments won't have one (only new ones)
- Package items in cart are quantity=1, cannot be duplicated (same package can't be added twice)
- Product `hours` field is null for many courses in DB — package total hours may show 0
- `handleQuickRegister` sets firstName = phone number — should be updated by staff later
