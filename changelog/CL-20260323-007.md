## Summary

อัปเดต Notion Task Board database schema ผ่าน Notion MCP เพื่อรองรับ task type fields ใหม่ และแก้ไข column name mismatches ที่ทำให้ push พัง รวมถึงอัปเดต notionRepo.js ให้ sync ข้อมูลครบทุก field

---

## Changes

### Notion DB — `36767d01d85345fa97c0c6e5ed20c5e3` (via MCP)
**Column renames (fix mismatch กับ CRM code):**
- `Task Name` → `Task` (title column)
- `Assigned To` → `Assignee`

**Priority options — aligned กับ CRM:**
- เพิ่ม: L2 · Important, L3 · Routine, L4 · Deferrable, L5 · Optional
- ลบ: L2 · Normal, L3 · Low (legacy)

**Status options:**
- เปลี่ยน `🟠 Pending` → `🟠 Urgent` (ตรงกับ STATUS_TO_NOTION)
- เพิ่ม `⏸ On Hold` (สำหรับ CANCELLED tasks)

**New columns:**
- `Task Type` — Select: งานวันเดียว / งานต่อเนื่อง / โปรเจค
- `Start Date` — Date
- `Time` — Rich Text (format: "HH:MM" หรือ "HH:MM–HH:MM")
- `Milestones` — Rich Text (plain text summary, 1 line per milestone)

### `src/lib/repositories/notionRepo.js`
**New constants:**
- `TASK_TYPE_TO_NOTION` / `TASK_TYPE_FROM_NOTION` — Thai label ↔ CRM enum
- `formatMilestonesForNotion()` — format milestones array → readable text

**`pushTaskToNotion()` — push new fields:**
- `Task Type` select → TASK_TYPE_TO_NOTION[task.taskType]
- `Start Date` → task.startDate (RANGE/PROJECT เท่านั้น)
- `Time` → "HH:MM–HH:MM" (SINGLE ที่มี timeStart)
- `Milestones` → formatted text (PROJECT เท่านั้น)

**`pullTasksFromNotion()` — pull new fields:**
- อ่าน `Task Type`, `Start Date`, `Time` จาก Notion page properties
- parse `Time` string → timeStart / timeEnd
- import taskType/startDate/timeStart/timeEnd เมื่อสร้าง task ใหม่จาก Notion

**Mapping fixes:**
- `STATUS_FROM_NOTION`: `⏸ On Hold` → `CANCELLED` (เดิม PENDING); เพิ่ม `🟠 Pending` legacy fallback
- `PRIORITY_FROM_NOTION`: เพิ่ม `L5 · Optional`, legacy `L2 · Normal` และ `L3 · Low` fallbacks

## Known Gotchas
- Milestones push เป็น plain text ใน Notion — pull กลับมาจะ set milestones=null (ไม่ restore JSON)
- ต้องเช็ก column names ทุกครั้งที่ migrate Notion workspace ใหม่ — push จะ fail แบบ silent ถ้า column ไม่ตรง
- QStash schedule ยังคง pull ทุก 15 นาที — แต่จะไม่ restore milestones จาก Notion (one-way for this field)
