**Type:** MINOR

## Summary

Implements a full audit trail system with approval workflow.
Every high-stakes action is logged with before/after snapshots.
Actions requiring approval (ROLE_CHANGE, EMPLOYEE_DEACTIVATE, etc.)
enter PENDING_APPROVAL status until a MANAGER/OWNER approves or rejects.

## Known Gotchas

- **Audit log failure is non-blocking** — logAction errors are caught and logged, never bubble up to caller
- **LOGIN_FAILED actorId** — null when user not found in DB (email unknown)
- **IP / userAgent** — not yet captured (NextAuth authorize() has no req access). Will add in Phase 35 via custom signIn callback
- **Approval enforcement** — PENDING_APPROVAL is advisory only in this phase; actual enforcement (block action until approved) is Phase 35
