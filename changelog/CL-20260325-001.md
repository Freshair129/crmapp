## Summary

Marketing domain ปรับโครงสร้างระบบ sync ครั้งใหญ่:
- เปลี่ยนจาก SSE/eventBus → **Pusher WebSocket** สำหรับ real-time inbox
- เปลี่ยนจาก Vercel Cron Hourly (Pro feature) → **QStash scheduled HTTP** (Hobby-compatible)
- เปลี่ยน sync-hourly จาก per-ad loop → **Facebook Batch API** (1 call/campaign แทน N calls/ad)
- เพิ่ม metrics ใหม่ 10+ ตัว, ตาราง demographics + placement
- Historical backfill 2025-12-14 → 2026-03-25 (789 rows main metrics)
- ตั้ง **Doppler** สำหรับ secrets management

## Known Gotchas

- **FB_ACCESS_TOKEN หมดอายุ ~2 ชม.** — ต้อง renew จาก FB Explorer แล้วอัปเดต Doppler + Vercel
  - Exchange short-lived → long-lived (60 วัน): `GET /oauth/access_token?grant_type=fb_exchange_token&client_id=855039874236973&client_secret=...&fb_exchange_token=...`
  - ถ้า exchange fail ด้วย "is_transient" retry ใหม่ หรือ generate fresh token จาก Explorer
- **FB error 99** สำหรับ demographics/placement breakdown บน date range เก่า (>30 วัน) — ข้อมูลเพิ่มได้แค่จาก sync-daily ไปข้างหน้า
- **Vercel Deployment Protection bypass** — QStash ต้องส่ง header `X-Vercel-Protection-Bypass: j26rvrhgwLGudOOCKlQP4HFopxN8VAKZ`
- **sync-hourly route.js** ต้อง export `POST` handler (ไม่ใช่ `GET`) — QStash ส่ง POST
- **Doppler → Vercel sync** ยังไม่ได้ตั้ง automatic integration — ต้อง update Vercel env vars ด้วยตนเองหลัง Doppler เปลี่ยน
