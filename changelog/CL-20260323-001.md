## Summary

Phase 34 เพิ่ม multi-role support ให้ระบบ RBAC ของ V School CRM — พนักงาน 1 คนสามารถถือหลาย role พร้อมกันได้ (เช่น อ้อย = EMPLOYEE + ADMIN_SALES) โดย permission เป็น additive union และเพิ่ม OWNER role สำหรับคุณวอเตอร์ (บทบาท executive read-only)

- `Employee.roles String[] @default([])` — new field

### `src/lib/rbac.js`
- เพิ่ม `OWNER` role (L4.5, ระหว่าง MANAGER และ DEVELOPER)

### `src/lib/authOptions.js`

- `jwt()` — seed และ refresh `token.roles` ทุก 5 นาที

### `src/lib/sidebarProfiles.js`

## Migration Notes

```sql
-- Applied automatically via Supabase execute_sql
ALTER TABLE employees ADD COLUMN IF NOT EXISTS roles TEXT[] NOT NULL DEFAULT '{}';
UPDATE employees SET roles = ARRAY[role] WHERE roles = '{}';
```

---

## Known Gotcha

- **Backward compat**: `session.user.role` (primary, string) ยังอยู่ — ไม่ break existing code
- **OWNER ≠ ADMIN**: OWNER ไม่มีสิทธิ์แก้ไข — เป็น read-only executive view เท่านั้น
- **Multi-role assign**: ใช้ SQL ตรงๆ หรือ Employee edit UI (ยังไม่มี UI สำหรับ multi-role assign)
- **roles[] ว่าง**: authOptions fallback → `[role]` เพื่อป้องกัน edge case
