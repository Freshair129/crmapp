# ADR-004: Go-to-Market Strategy — Culinary Schools First

**Date:** 2026-03-24
**Status:** Accepted
**Decider:** Founder

---

## Context

มี 2 target market คือ culinary schools และ restaurants
ต้องตัดสินใจว่าจะเริ่มจากกลุ่มไหนก่อน และหาลูกค้าด้วยวิธีใด

---

## Decision

**เริ่มจาก Culinary Schools ก่อน** ด้วย outreach ตรง (direct DM + referral)

---

## Rationale

### ทำไม Culinary School ก่อน Restaurant

| | Culinary School | Restaurant |
|---|---|---|
| Demo ที่มี | V School = exact match | ต้องสร้าง table/order module เพิ่ม |
| Sales cycle | สั้น (เจ้าของตัดสินใจเอง) | ยาวกว่า (หลายคน involve) |
| Pain point | ตรงกับ product 100% | ต้องการ POS เพิ่มที่ยังไม่มี |
| Community | แน่น referral ดี | กระจัดกระจาย |
| Risk | ต่ำ | สูง (ต้องพัฒนาเพิ่ม) |

### Ideal First Customer Profile

```
- โรงเรียนสอนทำอาหาร / ขนม / กาแฟ / เบเกอรี่
- กรุงเทพฯ หรือเชียงใหม่
- รับนักเรียน 5–30 คน/รุ่น
- มี Facebook Page active
- รับจองผ่าน DM / Line
- ยังใช้ Excel หรือ Google Sheet อยู่
```

---

## Channels (เรียงตาม ROI)

### Channel 1: V School Referral (เร็วที่สุด)
```
Action: ขอให้ V School แนะนำเพื่อนเจ้าของโรงเรียน
Why: วงการอาหารในไทยรู้จักกันหมด
Target: 1-2 referral ใน 30 วัน
```

### Channel 2: Direct Outreach — Facebook / Instagram
```
Action:
  1. Search "cooking class Bangkok", "สอนทำขนม", "barista class"
  2. เลือก account ที่ post สม่ำเสมอ (active business)
  3. DM ด้วย script สั้น + link demo video

Target: outreach 20 ราย → ปิด 2 ราย (10% conversion)
```

### Channel 3: Google Maps
```
Action: Search "cooking school Bangkok" → โทรหา / inbox โดยตรง
Why: ธุรกิจที่ขึ้น Google Maps = serious business
```

### Channel 4: Facebook Groups
```
Groups เป้าหมาย:
  - "สอนทำอาหาร Thailand"
  - "Baking & Pastry Thailand"
  - "คนทำขนมขาย"
  - "Barista Thailand"

Action: โพสต์ case study V School (ขออนุญาตก่อน)
```

---

## DM Script (สั้น + ตรง)

```
สวัสดีครับ/ค่ะ เห็นว่าทาง [ชื่อโรงเรียน] รับนักเรียนผ่าน Facebook
ผมพัฒนาระบบจัดการโรงเรียนสอนทำอาหารที่ใช้งานอยู่ที่ V School ครับ
รวม inbox, ตาราง, stock, payment ไว้ในที่เดียว
ขอนัด demo 20 นาทีได้ไหมครับ? ไม่มีค่าใช้จ่ายครับ
```

---

## Demo Flow (20 นาที)

```
นาที 0-3:   ถามถึง pain point ปัจจุบัน (Excel? Line OA?)
นาที 3-15:  demo live system (V School)
  - Unified inbox FB + LINE
  - จองคลาส + ตาราง
  - เช็ค stock วัตถุดิบ
  - ดู payment + slip OCR
นาที 15-18: ROI — "ระบบนี้ทำแทนพนักงาน part-time 1 คน"
นาที 18-20: ถามว่าสนใจ setup ไหม + quote ราคา
```

---

## Success Metrics (90 วันแรก)

| Metric | Target |
|---|---|
| Outreach ส่งออกไป | 30 ราย |
| Demo calls | 6 ราย (20%) |
| Closed deals | 2 ราย (33% of demo) |
| Setup revenue | 30,000-50,000 บาท |
| Monthly recurring | 10,000 บาท/เดือน |

---

## Consequences

- **บวก:** เร็ว, ต้นทุนต่ำ, ใช้ proof ที่มีอยู่แล้ว
- **ลบ:** manual outreach ใช้เวลา
- **แก้ด้วย:** ทำ demo video 1 ครั้ง → ใช้ซ้ำได้ทุก outreach
